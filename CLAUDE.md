# Bookmarks that come back

Every prompt in this project arrives with a `<saved-bookmarks>` block: the user's saved X
bookmarks from GBrain, injected by `code/resurface-hook.mjs`. Follow its instructions: when a
task request comes in, open with the 1 to 3 bookmarks that directly help, then do the task.
If none clearly fit, don't mention bookmarks. This is the product being demoed, not noise.
